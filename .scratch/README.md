# Scratch Workspace

This directory is used for local issue tracking, task specs, wayfinding maps, and throwaway prototypes.

## Structure

```
.scratch/
├── <feature-slug>/
│   ├── spec.md                     # Feature specification (generated by /to-spec)
│   └── issues/                     # Tracer-bullet ticket files (generated by /to-tickets)
│       ├── 01-<ticket-slug>.md
│       ├── 02-<ticket-slug>.md
│       └── ...
└── <effort-slug>/
    ├── map.md                      # Decision map (used by /wayfinder)
    └── issues/
        └── NN-<slug>.md
```
