# LNG Domain Glossary

Core domain model vocabulary for this project. Maintained and updated through the `/domain-modeling` and `/grill-with-docs` skills.

## Rules

- **Be opinionated**: When multiple terms exist for the same domain concept, define the canonical one and list discarded alternatives under `_Avoid_`.
- **Keep definitions tight**: 1-2 sentences defining what the concept IS.
- **Domain-specific terms only**: Standard software engineering patterns (ORM, REST, timeout, retry) do not belong here; only terms native to this application's business problem belong here.
